## Architecture Notes

Server Philosophy: Keep it "dumb" for privacy
- Current: Server is a simple relay (no message storage, no content inspection)
- Future: Server can queue encrypted blobs it can't read
- Never: Server should never inspect/store plaintext messages

Client Philosophy: Smart client, all privacy protections client-side
- Current: Client manages all conversation state, buffering, UI
- Future: Client handles encryption/decryption, key management
- Benefit: Server compromise doesn't reveal message contents
